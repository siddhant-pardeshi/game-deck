Six worlds · zero installs

THE GAME DECK

Handcrafted browser games with a living mascot guide. Race a hovercar GP, hold the line against a saucer siege, fly the dawn mail run, carve a sunset point, outrun the last metro — or just light the lanterns on one small warm island.

Every game runs on phones and desktops, saves your progress locally, and respects your mute button.

▾

How the deck grows

Each game here ships from one shared game kit — a mascot engine, a synth audio engine, and a responsive game shell — so every new world keeps the same feel, the same accessibility, and the same one-tap start. The build recipe is public: read the game factory.

Made by Siddhant Pardeshi. All games, art, characters and music are original work.
